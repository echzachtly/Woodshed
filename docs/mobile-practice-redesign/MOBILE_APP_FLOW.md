# Mobile App Flow

## Core Principle

Mobile should keep users inside practice flow with minimal interruption.

The app should prioritize:
- rapid repetition
- low-friction playback
- persistent practice context
- single-tap interactions

---

# Primary Practice Flow

Open app
→ Select project
→ Select phrase or freeform playback
→ Begin practice
→ Switch between Loop Phrase / Focus Loop / Play Through
→ Adjust speed
→ Restart rapidly
→ Continue practicing without navigation interruption

---

# Structured Practice Flow

Project
→ Phrase
→ Optional Focus Loops

Focus loops remain contextual to the parent phrase.

They should not appear as standalone navigation objects.

---

# Freeform Practice Flow

Users may:
- upload songs
- scrub waveform
- set ad hoc loop areas
- slow playback
- practice without saved phrases

This is valid behavior and should be supported naturally.

---

# Focus Loop Flow

When a phrase contains focus regions:

- Focus Loop becomes available
- selecting a focus region activates Focus Loop
- users can quickly switch between:
  - Loop Phrase
  - Focus Loop
  - Play Through

Focus loops should feel like practice targets, not nested navigation.

---

# Restart Flow

Restart is one of the most important interactions in the app.

Users should be able to:
- restart quickly
- restart repeatedly
- restart without menu interaction

The app should optimize for uninterrupted repetition.

---

# Lead-In Context Flow

If enabled:
- playback begins before the phrase start
- user hears musical lead-in context
- phrase then loops normally

Lead-in context should apply primarily to initial playback start.

---

# Persistent Context

The app should remember:
- last phrase
- last focus loop
- last speed
- last playback mode
- recent waveform position where practical

This minimizes interaction friction during repeated practice sessions.

---

# Navigation Philosophy

Avoid deep navigation stacks.

The app should feel like:
- staying inside practice

NOT:
- navigating software

---

# Mobile Control Philosophy

Controls should remain quickly accessible.

Avoid:
- hidden primary actions
- modal-heavy interaction
- excessive taps
- complex menus

---

# Landscape Flow

Landscape should provide:
- expanded waveform visibility
- easier music stand usage
- enhanced hands-free workflows

Without becoming a separate application experience.
