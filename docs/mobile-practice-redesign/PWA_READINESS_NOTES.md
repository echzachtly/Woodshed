# PWA Readiness Notes

**Manual install / standalone checks:** see [`PWA_TESTING_CHECKLIST.md`](./PWA_TESTING_CHECKLIST.md).

## Direction

Woodshed mobile should evolve into a strong Progressive Web App (PWA) experience before native iOS development is considered.

---

# Goals

Prioritize:

- install-to-home-screen
- fullscreen app behavior
- fast launch experience
- app-like interaction feel
- mobile responsiveness

---

# Why PWA First

Benefits include:

- one codebase
- faster iteration
- easier deployment
- lower maintenance burden
- faster product validation

---

# Native iOS Strategy

Native iOS is intentionally deferred.

The product should first validate:
- practice workflows
- repetition ergonomics
- mobile retention
- hands-free interaction patterns

---

# Future PWA Opportunities

Potential future improvements:

- offline caching
- recent project caching
- faster reload behavior
- install prompts
- persistent session restoration

---

# Non-Goals

Do not prematurely optimize for:

- background playback
- advanced native APIs
- native-only interaction systems
- App Store deployment

The workflow matters more than distribution right now.
