# Mobile UI/UX Guidelines

## Design Goals

The mobile app should feel:

- calm
- immediate
- touch-friendly
- musician-native
- repetition-focused
- low-friction

---

# Touch Ergonomics

Prioritize:
- large touch targets
- thumb reach
- fast restart access
- minimal precision requirements

Avoid:
- tiny controls
- dense editing handles
- precision-heavy gestures

---

# Persistent Controls

Core playback controls should remain persistently accessible.

Prioritize:
- play/pause
- restart
- loop mode
- speed control
- focus loop switching

Avoid hidden-control media-player patterns.

---

# Waveform Guidelines

The waveform should remain interactive but lightweight.

Support:
- scrubbing
- tap-to-seek
- scrolling
- zooming where appropriate

Avoid:
- desktop-style editing density
- excessive overlays
- cluttered markers

---

# Focus Loop UI

Focus loops should feel:
- lightweight
- contextual
- rapidly accessible

Good candidates:
- chips
- pills
- horizontal selectors

Avoid:
- nested menus
- heavy inspector panels

---

# Visual Density

Keep the app:
- clean
- spacious
- readable

But avoid oversized mobile spacing that slows interaction.

---

# Portrait vs Landscape

Portrait:
- primary experience
- thumb-friendly
- quick practice flow

Landscape:
- enhanced waveform visibility
- music stand friendliness
- hands-free practice support

Use adaptive layouts rather than separate interfaces.

---

# Interaction Philosophy

Every extra tap interrupts practice.

Optimize around:
- single-tap workflows
- muscle-memory interaction
- rapid repetition

---

# Do Not Become Desktop Lite

Mobile is not a compressed desktop editor.

Avoid:
- inspector panels
- dense metadata
- editing-heavy interactions
- authoring workflows
