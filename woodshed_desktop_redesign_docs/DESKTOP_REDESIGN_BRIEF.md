# Woodshed Desktop Redesign Brief

## Product Direction

Woodshed desktop should become a sleek, DAW-inspired phrase creation and editing workspace.

The desktop app is for creating practice material.

The mobile app is for using that material during focused practice.

## Core Positioning

Woodshed is not a DAW.

Woodshed is the fastest way to turn music into deliberate practice.

## Desktop Purpose

Desktop should prioritize:

- Importing songs
- Creating phrases
- Editing loop boundaries
- Naming and organizing practice material
- Adding notes
- Creating lightweight segments inside phrases
- Preparing material for mobile practice

## Mobile Purpose

Mobile should prioritize:

- Practicing saved phrases
- Looping
- Speed control
- Repetition
- Focused daily use

## Design Goal

Desktop should feel like:

- Ableton-inspired
- Sleek
- Serious
- Focused
- Fast
- Intuitive

It should not feel like:

- A stretched mobile app
- A generic web dashboard
- A full DAW
- A cluttered productivity tool

## Key UX Principle

DAW-inspired, not DAW-complex.

Borrow the confidence, spatial hierarchy, and timeline-first workflow of Ableton.

Do not borrow unnecessary production complexity.
