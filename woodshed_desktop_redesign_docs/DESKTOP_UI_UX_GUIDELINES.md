# Woodshed Desktop UI/UX Guidelines

## Desktop Identity

The desktop version should feel like a focused phrase-authoring studio.

It should not feel like a mobile app enlarged for desktop.

## Visual Priorities

1. Main waveform
2. Phrase editing tools
3. Transport controls
4. Bottom inspector
5. Header utilities

## Layout Rules

- Avoid narrow centered mobile-style layouts on desktop.
- Use the full desktop canvas intelligently.
- Keep waveform interaction central.
- Avoid persistent left sidebar in this pass.
- Use a bottom inspector panel instead of stacked mobile cards.
- Make the bottom panel hideable.
- Keep the app single-window and focused.

## Ableton-Inspired, Not Ableton-Complex

Borrow:

- Timeline-first layout
- Bottom inspector concept
- Compact transport controls
- Serious workstation feel

Avoid:

- Dense DAW terminology
- Multi-track complexity
- Mixer-style UI
- Production features
- Detachable/resizable advanced panels

## Tone

The app should feel:

- Sleek
- Calm
- Fast
- Intentional
- Musician-friendly

## Interaction Guidelines

Phrase creation should be extremely fast.

Target workflow:

Select region → create phrase → name phrase → save.

Avoid burying primary actions in menus.

## Desktop vs Mobile

Do not compromise desktop to match mobile.

Desktop is for creation.

Mobile is for practice.
